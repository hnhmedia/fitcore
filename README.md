# AeroFit AI — Smart Workout & Body Composition Tracker with Gemini

An elite, high-performance web application built for serious lifters and fitness enthusiasts. Powered by React, Vite, Tailwind CSS, Recharts, and Google Gemini.

---

## 🚀 Key Features

### 1. 🏋️‍♂️ Live Workout Tracking & Logging
- **Dynamic Set Logging**: Add/adjust weights, reps, set types (warmup, normal, dropset).
- **Interactive Checkboxes**: Completing a set auto-initiates the rest timer.
- **Finish Exercise Toggle**: Mark exercises completed with clear visual feedback (`Finish Exercise ✓`).
- **Full Workout Session Persistence**: Active workout sessions are automatically preserved in local storage so refreshing the page or mobile sleep will never lose your session.
- **Celebratory Workout Summary**: Total tonnage/volume moved, total sets/reps completed, duration timer, and personal notes.

### 2. ⏱️ Rest Timer with Audio & Haptics
- Built-in Web Audio API synthesized chimes (countdown pips on 3, 2, 1, and chime on zero).
- Flexible controls: `+15s`, `-15s`, `+30s`, quick presets (30s, 60s, 90s, 120s, 180s), pause/resume, and skip.
- Floating minimized pill option so you can inspect upcoming exercises while the timer counts down.

### 3. 🤖 Gemini AI Integration & Routine Import/Export
- **Updated to `models/gemini-3.8-flash`**: Migrated to the latest Google Gemini 3.8 Flash model using Google AI Studio's **Interactions API** (`/v1beta/interactions`) with automatic fallback to `/v1beta/models/gemini-3.8-flash:generateContent`.
- **Interactive AI Coach**: Tap the **AI Coach** button in the top navigation to chat directly with your coach about nutrition, weekly volume, or breaking plateaus.
- **Biomechanical Exercise Swapping**: Tap the 🔄 button next to any exercise to have Gemini 3.8 Flash recommend 3 equivalent exercises (e.g. swapping barbell squats for hack squats or leg press if equipment is taken).
- **Barbell Plate Calculator**: Enter any weight to visually see exactly what plates to load onto each side of the bar.
- **Gemini Routine Architect**: Generate complete, tailored workout splits based on your goal (Hypertrophy, Strength, Fat Loss), training experience, days per week, and available equipment.
- **Reload / Import Gemini Routines**:
  - Paste ANY freeform text or JSON generated by Gemini into the app.
  - The smart parser automatically structures exercises, sets, target reps, and weights into an executable workout.
- **Export Prompt for Gemini Web**: Copy an optimized prompt with one click to chat with Gemini on the web, then paste the response straight into the app.

### 4. 📈 Weekly Progressive Overload Analytics
- Answers: *"Am I increasing weights or not?"*
- Calculates the weekly progression rate across all your lifts.
- Badges each exercise:
  - 🟢 **Increasing Weights ↑** (+kg delta)
  - 🟡 **Rep Progression / Holding Steady →**
  - 🔴 **Plateau / Deload ↓**
- Interactive Recharts graph of top set weight and estimated 1-Rep Max (1RM) over time.
- Weekly total volume bar chart.
- **Gemini Overload Coach**: Ask Gemini for personalized advice on how to break current plateaus.

### 5. 📏 Body Composition & Measurements (Chest & Stomach)
- Track **Stomach / Waist (cm)**, **Chest (cm)**, **Weight (kg/lbs)**, **Arms**, **Thighs**, and **Body Fat %**.
- **AI Body Recomposition Engine**:
  - Detects if you are in true **Body Recomposition** (belly/stomach waist dropping while chest/muscle expands).
  - Identifies **Clean Bulking**, **Cutting / Fat Loss**, or **Excessive Calorie Surplus**.
  - Provides estimated muscle gain vs fat loss rates and tailored nutrition/training recommendations.
- Interactive multi-line chart comparing Stomach vs Chest vs Weight over time.
